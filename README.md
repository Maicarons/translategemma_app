# Translategemma App

A real-time translation application built with Vue 3, Capacitor, and MediaPipe.

## Features

- Text translation with speech synthesis
- Voice translation with speech recognition
- Image translation with MediaPipe
- Multi-language support
- Settings panel with language configuration
- Responsive design for both web and mobile

## Getting Started

### Prerequisites

- Node.js (v18+)
- pnpm
- Capacitor CLI

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Maicarons/translategemma_app.git
   cd translategemma_app
   ```

2. Install dependencies
   ```bash
   pnpm install
   ```

3. Add model file
   - Download the `translategemma-4b-it-int8-web.task` model file
   - Place it in the `public/models/` directory

### Development

1. Start the development server
   ```bash
   pnpm run dev
   ```

2. Build for production
   ```bash
   pnpm run build
   ```

### Mobile Build

1. Sync with Capacitor
   ```bash
   pnpm run sync
   ```

2. Build for Android
   ```bash
   pnpm run android
   ```

## Project Structure

```
├── public/              # Static assets
│   └── models/          # Model files (not tracked by git)
├── src/                 # Source code
│   ├── components/      # Vue components
│   ├── i18n/            # Internationalization files
│   ├── router/          # Vue Router configuration
│   ├── services/        # Service modules
│   ├── utils/           # Utility functions
│   ├── views/           # Page components
│   ├── App.vue          # Root component
│   └── main.js          # Entry point
├── android/             # Android project (generated by Capacitor)
├── .gitignore           # Git ignore file
├── capacitor.config.json # Capacitor configuration
├── package.json         # Package configuration
└── vite.config.js       # Vite configuration
```
